## No-Paid-API Policy

The Nexa AI MVP must not depend on paid APIs. Core functionality should remain useful through local logic, SQLite memory, and free/public internet sources only when live external information is required.

## Low-End Laptop Policy

Nexa AI must be designed for low-end Windows laptops. The MVP should avoid heavy local AI models, unnecessary background processing, aggressive polling, and wasteful resource usage so the assistant remains responsive on modest hardware.
