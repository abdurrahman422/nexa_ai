# Nexa AI — Backend Module Plan

| Module | Purpose | Priority | Planned Main Files | Expected API Endpoints | Expected Database Tables | Safety Rules |
|---|---|---|---|---|---|---|
| API Routers | Expose local HTTP interfaces for frontend-backend communication | MVP | `api/routes/health.py`, `profile.py`, `commands.py`, `apps.py`, `system.py`, `voice.py`, `files.py`, `web.py`, `reminders.py`, `contacts.py`, `security.py`, `smart_home.py` | `/api/health`, `/api/profile`, `/api/commands`, `/api/apps`, `/api/system`, `/api/voice`, `/api/files`, `/api/web`, `/api/reminders`, `/api/contacts`, `/api/security`, `/api/smart-home` | None directly | Routers must validate input and delegate business logic |
| Core Config | Manage environment, logging, startup, and backend lifecycle | MVP | `core/config.py`, `core/logging.py`, `core/startup.py` | `/api/health` indirectly | `app_metadata` later if needed | Must not expose secrets or unsafe defaults |
| Database | Provide SQLite persistence and future migrations | MVP | `database/connection.py`, `database/models.py`, `database/repositories/`, `database/migrations/` | None directly | All planned SQLite tables | Sensitive fields should be minimized |
| Command Engine | Interpret user commands before execution | MVP | `command_engine/normalizer.py`, `synonyms.py`, `matcher.py`, `intents.py`, `slots.py`, `planner.py` | `/api/commands` | `command_aliases`, `intent_examples`, `interaction_logs` | Raw user text must never execute directly |
| App Launcher | Open approved apps and websites | MVP | `automation/apps/service.py`, `automation/apps/resolver.py` | `/api/apps` | `app_shortcuts`, `website_shortcuts` | Unknown executable paths require validation |
| System Control | Control supported Windows functions | MVP | `automation/system/service.py`, `automation/system/actions.py` | `/api/system` | `permission_rules`, `security_events` | Shutdown/restart must require confirmation |
| YouTube & Browser Automation | Handle browser searches and supported media controls | MVP | `automation/browser/service.py`, `automation/browser/youtube.py` | `/api/commands`, possible `/api/browser` later | `interaction_logs`, `browser_preferences` later | Sensitive browser actions must not run implicitly |
| Voice STT | Convert microphone input into text | MVP | `voice/stt.py`, `voice/session.py` | `/api/voice` | `voice_settings` later if needed | Low-confidence transcripts should not trigger sensitive actions |
| Text-to-Speech | Produce spoken responses | MVP | `voice/tts.py`, `voice/response_queue.py` | `/api/voice` | `user_preferences` | User must be able to mute or disable voice output |
| File Search & Organizer | Search and cautiously organize files | MVP | `files/search.py`, `files/indexer.py`, `files/organizer.py` | `/api/files` | `file_index`, `file_action_history` | Move/rename require confirmation; deletion excluded from MVP |
| Web Intelligence | Fetch weather, news, dictionary, and basic web data from free sources | MVP | `web/weather.py`, `web/news.py`, `web/dictionary.py`, `web/cache.py` | `/api/web` | `web_cache` | Must fail honestly when sources are unavailable |
| PDF & Documents | Parse, chunk, search, and summarize supported documents | MVP | `pdf/parser.py`, `pdf/chunker.py`, `pdf/query.py` | likely `/api/files` initially, dedicated `/api/documents` later | `documents`, `document_chunks` | Must not modify source documents without user intent |
| Reminders & Tasks | Manage reminders, tasks, and study scheduling | MVP | `scheduler/reminders.py`, `scheduler/tasks.py`, `scheduler/notifications.py` | `/api/reminders` | `reminders`, `tasks` | Ambiguous time requests require clarification |
| Contacts & Drafts | Store contacts and generate local message drafts | MVP | `contacts/service.py`, `contacts/drafts.py` | `/api/contacts` | `contacts`, `message_drafts` | Never auto-send messages in MVP |
| Security & Permissions | Enforce confirmations, permissions, and audit logging | MVP | `security/policies.py`, `security/confirmations.py`, `security/audit.py` | `/api/security` | `permission_rules`, `security_events` | Sensitive actions must be checked before execution |
| WebSocket Events | Publish real-time backend events to the frontend | MVP | `events/bus.py`, `events/websocket.py`, `events/schemas.py` | WebSocket channel | optional event log later | Events must not leak unnecessary sensitive data |
| Smart Home ESP32 | Support future device control over local network | Future | `smart_home/devices.py`, `smart_home/client.py`, `smart_home/service.py` | `/api/smart-home` | `smart_devices` | Critical device actions may require confirmation |
