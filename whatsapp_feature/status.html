Nexa · WhatsApp text-send

নতুন extension চালু করার আলাদা entry point আছে। পুরোনো launcher নিজে থেকে এটি ব্যবহার করে না। বাস্তবে message পাঠানো এখনো যাচাই হয়নি।

Draft command লেখা তৈরি বা draft link খোলে; Send চাপবে না। স্পষ্ট send command-এর জন্য Security Center-এর WhatsApp Web Sending চালু থাকতে হবে।

ফলঅর্থ ও পরের কাজ
login_requiredQR scan করে login করো। একই request ID দিয়ে আবার command দাও; কোনো message queued নেই।
draft_present / text_mismatchSend হয়নি। Draft review/clear করে একই request ID দিয়ে retry করো।
wrong_chatRecipient নিশ্চিত হয়নি; কিছু পাঠানো হয়নি।
submittedনতুন outgoing message দেখা গেছে; server acceptance বা delivery নিশ্চিত নয়।
sentSent acknowledgement দেখা গেছে; recipient delivery নিশ্চিত নয়।
delivered / readসংশ্লিষ্ট acknowledgement দেখা গেছে। সব account/UI-তে read status পাওয়া যাবে না।
unknownপাঠানো হয়ে থাকতে পারে। WhatsApp দেখে যাচাই করো; নতুন ID দিয়ে আবার পাঠিও না।
ledger_errorRequest record সমস্যা। State মুছে নতুন করে পাঠিও না; আগে WhatsApp-এ ফল যাচাই করো।

পুরোনো chat UI সফল ফলকে submitted হিসেবে দেখাতে পারে; reply text-এ বিস্তারিত থাকবে। এই extension group, attachment, incoming-message reading বা auto-reply যোগ করে না।
