# Nexa AI — Project Structure

This repository is organized as a beginner-friendly, production-oriented monorepo.

## Top-Level Folders

- `frontend/` — future Electron + React + Vite + TypeScript UI
- `backend/` — future Python FastAPI automation backend
- `shared/` — shared schemas, API contracts, and project-wide references
- `docs/` — planning and architecture documents
- `scripts/` — future build, run, packaging, and setup scripts
- `tools/` — future developer utilities and diagnostics

This phase creates only the repository structure. Frontend and backend implementation will be added in later phases.
